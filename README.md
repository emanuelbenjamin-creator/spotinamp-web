# spotinamp-web

Página de presentación de **Spotinamp**, un reproductor para Windows con el aspecto del Winamp
clásico que pone la música de Spotify Premium.

Es un único archivo (`index.html`) sin dependencias, publicado con GitHub Pages.

Para verla en local:

```bash
python -m http.server 8766
```

Los enlaces de descarga y del repositorio están al principio del `<script>` de `index.html`
(`ENLACE_DESCARGA` y `ENLACE_REPOSITORIO`).

Spotinamp no está afiliado a Spotify ni a Winamp.
